Design Direction — Stage 5

UI & UX Plan

A world you stand inside, not an interface you operate.

The goal: a painted atmospheric night scene fills the entire screen. The player exists inside it. Every UI element floats as frosted glass at the screen edges — never covering the world unless called. This document is the complete implementation plan: layer architecture, color system, component inventory, animation catalog, and a 5-phase delivery roadmap.

1. Layer Architecture

Three stacked layers cover the full viewport. Their separation is the key structural decision — it keeps the painted scene unblemished while interactive and UI elements float above it.

Layer 3
Glass UI
React components — fixed-position edge anchors, backdrop-filter blur
position: fixed · z-index: 10–50 · pointer-events: auto · never center of screen
Layer 2
Canvas
Transparent canvas — shooting meteors, floating orbs, star field, player dot
position: fixed · z-index: 1 · background: transparent · pointer-events: none
Layer 1
Background
Static background-image (painted scene) + CSS aurora overlay gradients
position: fixed · z-index: 0 · pointer-events: none · background-size: cover

The center of the viewport is always world. UI lives at the four edges.

Glass Panel Recipe

Every floating panel uses these exact properties — no variation:

/* Every floating UI panel */
.panel {
  background:       rgba(8, 6, 28, 0.72);
  border:           1px solid rgba(130, 100, 220, 0.20);
  border-radius:    14px;
  backdrop-filter:  blur(20px) saturate(1.4);
  box-shadow:       0 4px 32px rgba(0,0,0,.45),
                     inset 0 1px 0 rgba(180,150,255,.08);
}
.panel:hover {
  border-color:     rgba(170, 140, 255, 0.35); /* border brightens on hover */
}

4. Background Scene Strategy

✓ Recommended

Static image + CSS aurora

Generate the scene painting with Midjourney or DALL-E 3. Export at 1920×1080 WebP. CSS radial gradients layer the aurora color bloom on top. Canvas composites meteors and stars over it.

Build time: 1–2 hrs · Quality: matches reference exactly

Alternative

Layered canvas scene

Build entire scene in Canvas 2D: gradient sky, silhouetted mountains + trees in bezier paths, water reflection with canvas transform, lantern glow with radial gradients.

Build time: 2–3 weeks · Quality: stylized, not painterly

Midjourney Prompt

Prompt:
fantasy night garden panorama, stone path with glowing lanterns, cherry blossom tree, waterfall, distant pagoda castle, reflective koi pond, purple flowers, fireflies, anime studio ghibli style, cinematic, wide angle, dark blue and deep purple night sky with aurora, warm lantern orange light, hyper-detailed, 16:9 --ar 16:9 --v 6

Run 4 variations, pick the strongest. Export as WebP (smaller than PNG, good browser support). The CSS aurora layers sit on top so the scene doesn't need to be perfect at the edges.

6. Animation Catalog

Name Description Layer
Shooting meteor trail Comet head (category-colored, 6px) with bezier trail (opacity 0→0.8→0, width 0→2px). Crosses screen diagonally over 3–6s, ease-out. Fires ~1 per 8–12s. Canvas
Star field twinkle Already implemented. Per-star sine-wave freq (0.3–1.7 Hz) and phase, color warm/cool variation, 4-pointed ✦ shape for brightest. Keep as-is. Canvas ✓
Meteor orb pulse Floating orbs breathe: scale 1→1.08→1 over 3s, glow radius expands. When player is near: border ring appears, brightness increases. Draws attention without distraction. Canvas
Firefly particles 8–12 small amber dots (2px) drift in slow random paths near foreground. Opacity 0.3–0.7, no trail. Adds life to scene edges. Canvas
Release button halo Center Release circle: faint pulse ring expands 100%→130% radius, opacity 0.6→0 on loop, 2.5s. CSS animation on ::after pseudo-element. CSS
Panel slide-in Panels entering screen use translateX(24px)→0 + opacity 0→1, 300ms ease-out-expo. Exit reverses. Respects prefers-reduced-motion. CSS
✦ Star transform When a meteor becomes a star: scale burst (1→1.6→1), color shifts to gold, lens flare cross expands and fades over 800ms. Canvas burst + CSS toast fires simultaneously. Canvas + CSS
Notification entrance Toast slides up from bottom-left: translateY(16px)→0 + opacity 0→1 over 350ms, ease-out. Auto-dismiss at 4s with reverse. Upgrade existing timing curve. CSS
