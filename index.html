What is Afterlight?

Afterlight is a persistent browser-based multiplayer game where players anonymously share small pieces of what they are carrying — a worry, a hope, a moment, a gratitude — as a meteor in a shared night sky. When another real player encounters that meteor and acknowledges it, it transforms permanently into a star.

The emotional promise is simple: something you carried alone can become something that was heard.

Afterlight is not therapy, diagnosis, crisis counseling, or a replacement for professional care. It is a social game centered on expression, recognition, and gentle connection.

The Mechanic in One Sequence

  1. A player opens the release interface, selects a category (burden, moment, hope, or gratitude), and writes a short anonymous message.
  2. The server runs safety checks. Approved messages enter the shared world as a glowing meteor.
  3. Another player walking through the world encounters the meteor. They read it. They choose one of five predefined responses: "I feel this too.", "You're not alone.", etc.
  4. The server records the resonance. The meteor transforms into a permanent star in real time — both clients see this simultaneously.
  5. The original writer receives a private notification: Someone heard you.
  6. The acknowledging player earns Light — a cosmetic resource used to grow a personal garden space.

Design Principles

One acknowledgment is enough The first genuine response transforms a meteor into a star. Additional responses are recorded as community resonance but do not change the writer's "worth."
No popularity metrics No public like counts, no follower scores, no leaderboards. The game should never make vulnerability feel like a competition.
Anonymous by default Players are anonymous to one another. The system maintains internal IDs for persistence and abuse prevention, but no public profile is required or displayed.
Structured interaction only Only predefined responses are available. No free-form player-to-player chat. This prevents harassment, manipulation, and unwanted contact while keeping the acknowledgment mechanic intact.
Safety is a product requirement Content safety, crisis flow, and moderation are first-class requirements built into the architecture from Stage 0 — not features added before launch.
Light is not a wellbeing score Light is a cosmetic game resource that unlocks garden items. It is not a public mental-health metric or a ranking of empathy.
